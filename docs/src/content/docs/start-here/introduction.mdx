# KoAkademy developer documentation

KoAkademy is a self-hosted school administration and learning platform. It is a production-capable beta: the repository provides a supported topology and automated validation, while each operator remains responsible for staging, backup, monitoring, privacy, and recovery.

## Pick your path

- **New contributor?** Start with [Development setup](./development/), read the [Architecture overview](./architecture/), then dive into **System Internals** — beginning with the [domain model](../system/architecture-domain/).
- **Maintainer?** The **Maintainers** section documents the [CI pipeline](../maintainers/ci/), the [release and versioning process](../maintainers/releases/), [repository automation](../maintainers/automation/), and the [documentation system](../maintainers/documentation/) itself.
- **Self-hosting?** Begin with [Installation](../self-hosting/installation/), then follow [Deployment](../self-hosting/deployment/) and [Configuration](../self-hosting/configuration/). The supported default is one HTTPS hostname with administration at `/admin`.
- **Operating a school on KoAkademy?** The [User Guide](../user-guide/introduction/) covers daily staff workflows, and **Enrollment Blueprints** covers no-code enrollment configuration.

## The stack at a glance

| Layer | Technology |
| ----- | ---------- |
| Backend | PHP 8.5, Laravel 12, nginx + PHP-FPM |
| Administration | Filament 5 with Shield permissions |
| Portals | Inertia 3, React 19, Tailwind CSS 4, shadcn/ui |
| Data | PostgreSQL, Redis (cache, sessions, queues) |
| Documents | `spatie/laravel-pdf` with Gotenberg |
| Tests | Pest 4 (parallel, SQLite in-memory) |
