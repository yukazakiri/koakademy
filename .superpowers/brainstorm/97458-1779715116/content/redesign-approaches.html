3 Redesign Approaches

Each approach hides the inspector differently. All include the full right-click menu you requested.

A

Full Canvas + Modal Edit

Inspector is completely removed. Canvas takes full width. Right-click shows all actions. "Edit" opens a modal with sidebar tabs.

Pros

  • Maximum canvas space for workflow visualization
  • Cleanest, most focused interface
  • Modal organizes complex config into digestible tabs
  • No accidental inspector clutter

Cons

  • Modal blocks canvas view while editing
  • More clicks to see node details
  • Context switching between canvas and modal
B

Collapsible Side Panel

Inspector becomes a collapsible panel on the right. Default state is collapsed (full canvas). Click a node or "Edit" from context menu to expand it.

Pros

  • Canvas is primary view by default
  • Inspector still accessible without modal
  • Can see canvas and config simultaneously
  • Familiar pattern for power users

Cons

  • Panel can feel cramped when open
  • Two different ways to access config (click node vs right-click Edit)
  • Less clean than full canvas
C

Floating Inspector Overlay

Inspector appears as a floating card near the selected node. Can be dragged, minimized, or dismissed. Canvas remains fully visible behind it.

Pros

  • Canvas always fully visible
  • Inspector contextually placed near active node
  • Can drag overlay to avoid blocking important nodes
  • Modern, dashboard-like feel

Cons

  • More complex to implement (dragging, positioning)
  • Can accidentally block other nodes
  • May feel cluttered with multiple overlays

My Recommendation: Approach A

Given your feedback that the current inspector is "too complicated and not organized," Approach A (Full Canvas + Modal Edit) best solves the problem by:

  • Completely removing the cramped inspector
  • Giving the canvas the full attention it deserves
  • Organizing node configuration into clean, navigable modal tabs
  • Keeping the workflow simple: see canvas → right-click → act or edit
